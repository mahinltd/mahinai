# MahinAi

MahinAi is a futuristic AI startup landing page and product concept website built with HTML, Tailwind CSS, and lightweight JavaScript. The project presents the MahinAi brand vision, ecosystem positioning, startup status, and contact channels in a premium dark-tech design.

## Overview

The website introduces MahinAi as an intelligence platform designed to bridge the gap between raw AI potential and practical execution. It targets students, creators, and builders by showcasing a polished narrative around context-aware AI, architecture generation, and accelerated product workflows.

## Project Highlights

- Premium dark UI with neon gradients and glassmorphism effects
- Responsive design for desktop and mobile screens
- Smooth scroll and animated sections
- Startup-focused storytelling and roadmap/status presentation
- GitHub and email contact actions
- Built as a lightweight static front-end experience

## Stack

- HTML5
- Tailwind CSS via CDN
- Font Awesome icons
- AOS animation library
- Vanilla JavaScript

## Local Run

Because this is a static site, you can open it directly in a browser:

```bash
start index.html
```

Or serve it locally with a simple static server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
